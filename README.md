# Notes & Interview Questions

A structured, interview-first knowledge base for a PHP/Laravel backend software engineer targeting 3–5 YOE roles and 10+ LPA opportunities.

## Coverage

- PHP: fundamentals, type system, functions, OOP, exceptions, namespaces/autoloading, Composer, security, performance, internals, testing, interview traps, machine rounds
- Laravel: architecture, request lifecycle, routing, middleware, controllers, validation, Eloquent, relationships, query builder, transactions, queues, events/listeners, jobs, caching, authentication/authorization, API resources, files/storage, mail/notifications, scheduling, testing, service container/providers, packages, performance, security, deployment, architecture and machine rounds
- Symfony: HTTP kernel, routing, controllers, DI, services, events, Doctrine, Messenger, security, forms/validation, console, cache, testing, architecture and machine rounds
- MySQL: SQL fundamentals, joins, aggregation, subqueries, CTEs, window functions, indexes, transactions, isolation, locks, MVCC, constraints, normalization, query plans, optimization, replication concepts and machine rounds
- OOP: principles, inheritance/composition, interfaces, traits, polymorphism, SOLID, design principles, patterns, PHP-specific OOP and machine rounds
- REST APIs: HTTP, REST constraints, resource design, status codes, validation, pagination, filtering, versioning, idempotency, authentication, authorization, rate limiting, caching, webhooks and observability
- Third-party APIs & integrations: OAuth/API keys, retries, timeouts, signatures, webhooks, reconciliation, idempotency, failure handling, provider adapters and production integration patterns
- Payment Integration: payment lifecycle, checkout, webhooks, signatures, idempotency, refunds, reconciliation, security and failure scenarios
- Angular: TypeScript foundations, components, templates, services, dependency injection, RxJS, forms, routing, guards, interceptors, HTTP, state patterns, performance and interview questions
- System Design: requirements, estimation, API/data modelling, caching, queues, consistency, scaling, load balancing, database choices, observability, reliability, security and backend case studies

## Depth standard

Each topic is intended to contain:

1. Concept notes from beginner to advanced.
2. PHP/Laravel/Symfony/MySQL-specific implementation details where applicable.
3. Common mistakes and interview traps.
4. Beginner, intermediate and 3–5 YOE interview questions.
5. Output/predict-the-result questions where relevant.
6. Practical coding/machine-round exercises.
7. Production scenarios and debugging questions.
8. A mastery checklist.

The goal is high coverage rather than a claim of literal certainty. No static document can guarantee every question an interviewer may invent; new or company-specific questions can always exist.

## Recommended study order

1. PHP fundamentals + type system
2. OOP + SOLID + design patterns
3. MySQL + SQL + transactions + optimization
4. Laravel internals and production development
5. REST APIs + authentication + security
6. Symfony fundamentals and architecture
7. Third-party APIs + payments
8. Testing + debugging + performance
9. System design
10. Angular/TypeScript as supporting full-stack knowledge

## Interview target

Primary target: PHP/Laravel backend roles around 3–5 YOE, with strong fundamentals and production-level reasoning. Secondary target: Symfony/full-stack roles.
