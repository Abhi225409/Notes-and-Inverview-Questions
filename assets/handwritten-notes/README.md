# Handwritten-Style Visual Notes

This folder contains zoomable SVG visual note sheets for the interview roadmap. SVG is used instead of low-resolution PNG so the notes remain sharp when zoomed in GitHub.

## Planned visual sets

- PHP
- OOP / SOLID
- MySQL
- Laravel
- REST APIs
- Symfony
- Third-party API integration
- Payment integration
- Angular
- System Design

Each visual sheet is a companion to the detailed Markdown notes, not a replacement for them.
